A tiny, deterministic program for the make.fun competition
"How Many Tabs Do You Have Open?". It writes one number, digits
only — an honest count of open browser tabs — to
`/output/entry.txt`:

> 137

The program checks the gate itself (digits only, 1–5 characters)
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
